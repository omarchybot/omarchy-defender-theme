# Omarchy Defender Theme

**The 1980 Williams Defender, as an Omarchy theme.** Space black, terrain
orange, scanner cyan, lander green, baiter magenta — every color sampled from
the actual game running in MAME, built from [Eugene Jarvis and Sam Dicker's
original 6809 source code](https://github.com/mwenge/defender).

The wallpapers are real emulator frames of source-built ROMs: nearest-neighbor
upscaled 9x (crisp authentic pixels), centered in 4K space black, with subtle
CRT scanlines.

## Install

Omarchy menu → Install → Style → Theme, then paste:

```
https://github.com/Jbennett111/omarchy-defender-theme
```

## Palette

| Color | Hex | In the game |
|---|---|---|
| accent / orange | `#ff5100` | planet terrain |
| green | `#00d100` | landers, HUD text |
| cyan | `#00e0e0` | scanner |
| red | `#ff2020` | mutants |
| magenta | `#ff00a0` | baiters |
| yellow | `#ffae00` | explosions |
| background | `#000000` | space |

## Lore

Made on a dual-boot Omarchy rig where the real Defender — assembled from the
1981-printout source, ROM checksums matching the original cabinet dumps —
runs as the screensaver. When the machine idles, the baiters come out.
